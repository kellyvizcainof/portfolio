# Portfolio UX / Frontend Audit

## What was improved

### 1. Positioning
The previous version introduced several capabilities at the same visual level. The redesign makes the main positioning immediate: Junior Web Layout Developer / Maquetadora Web Junior.

### 2. Hero hierarchy
The hero now uses one clear headline, one supporting role line and two primary actions. Supporting skills are reduced to small chips instead of competing buttons.

### 3. Project priority
Selected work now appears before background and experience. This helps recruiters reach evidence of practical work faster.

### 4. Project cards
Descriptions were shortened and each project now emphasizes the specific contribution: layout, mobile QA, content structuring or editorial/app QA.

### 5. Responsive behavior
Grid layouts collapse intentionally at tablet/mobile sizes. Buttons become full-width on small screens and floating profile labels become static to prevent overlap.

### 6. Code organization
The previous single-file approach was separated into:
- semantic HTML
- dedicated CSS
- lightweight JavaScript for language switching

### 7. Accessibility
Added:
- skip link
- visible keyboard focus states
- language attributes
- aria labels for navigation and language selection
- descriptive image alt text

### 8. Recruiter readability
The redesign reduces repetition and uses shorter scanning paths: positioning → selected work → experience → skills → contact.
