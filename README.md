# Kelly Vizcaíno — Portfolio Redesign

Bilingual responsive portfolio redesign created to present my work in web layout, WordPress, content operations and frontend development more clearly.

## Project goal

This project is a redesign of my previous portfolio. The objective was not only to refresh the visual style, but to improve hierarchy, responsive behavior, code organization and recruiter readability.

## Improvements made

- Stronger visual hierarchy in the hero section
- Clearer positioning as a Junior Web Layout Developer / Maquetadora Web Junior
- Real projects prioritized before background information
- Shorter, easier-to-scan project descriptions
- Improved mobile and tablet behavior
- More consistent buttons, spacing and cards
- Accessible focus states and skip link
- Language switcher for Spanish / English
- HTML, CSS and JavaScript separated into dedicated files
- CV and portfolio documents linked by language
